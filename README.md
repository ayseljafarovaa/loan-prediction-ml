# 🏦 Loan Prediction using Machine Learning & Ensemble Boosting

This repository contains a machine learning project focused on predicting loan approval status (`Loan_Status`) based on applicant demographic, financial, and credit history data.

## 📊 Project Overview
The goal of this project is to build and compare robust classification models to predict whether an applicant's loan will be approved or denied. The pipeline includes comprehensive data preprocessing, handling missing values, encoding categorical variables, feature engineering (creating dummy variables), and feature scaling.

## ⚙️ Models Implemented
The following models and techniques were trained and evaluated:
* **Decision Tree** (Base model)
* **Bagging Classifier**
* **Gradient Boosting Classifier**
* **XGBoost Classifier**
* **LightGBM Classifier**
* **CatBoost Classifier**
* **Voting Classifier** (Soft Voting Ensemble combining top boosting models)

## 📈 Evaluation Metrics
Models were evaluated using multiple performance metrics:
* Accuracy Score
* Confusion Matrix
* Precision, Recall, and F1-Score
* ROC-AUC Score

## 🛠️ Tech Stack & Libraries
* **Python** (3.13+)
* **Pandas & NumPy** (Data manipulation)
* **Scikit-learn** (Preprocessing, metrics, classical models)
* **XGBoost, LightGBM, CatBoost** (Advanced gradient boosting frameworks)
* **Matplotlib & Seaborn** (Data visualization)
